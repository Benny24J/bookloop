Kora Payment Gateway Integration

Official API integration specification & server credentials status.

How to configure Kora in this deployment:

  1. Sign up or login at Kora Developer Portal.
  2. Navigate to Settings → API Keys & Webhooks.
  3. Copy your Secret Key (starts with sk_test_... or sk_live_...).
  4. Open the .env file in the project root: 
    KORAPAY_SECRET_KEY=sk_test_your_key_here
KORAPAY_PUBLIC_KEY=pk_test_your_key_here
PORT=3000
  5. Restart the Node.js server. BookLoop will immediately route purchases through Kora's live checkout!

Integrated Official Kora Endpoints:

  • Initialize Charge: POST https://api.korapay.com/merchant/api/v1/charges/initialize
  • Verify Transaction: GET https://api.korapay.com/merchant/api/v1/charges/:reference
  • Webhook Receiver: POST /api/checkout/webhook
